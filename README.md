# 阿里云 ACP 刷题练习

本仓库目前提供**大模型方向**的本地刷题网页和 Markdown 题库，放在 [`llm_acp/`](llm_acp/) 中。仓库目录为其他 ACP 方向预留了并列位置。

> 题目根据课程内容整理，用于自主练习，**不是官方真题**。页面中的 80 分线只是练习参考线，不代表认证考试的合格标准。本仓库不包含课程 Notebook。

## 开始刷题

下载或克隆仓库后，双击本地的 [`llm_acp/刷题.html`](llm_acp/刷题.html) 即可打开。页面内已嵌入题目，不需要安装依赖、启动服务或联网。

首页可选择章节卷、综合卷或按课时练习。每次显示一道题；提交后查看正确答案和简析，再进入下一题。支持返回上一题、记录用时，以及在完成后查看成绩和完整错题回顾。答错的题会自动加入错题集，供后续重练。

## 题库与评分

| 试卷 | 题数 | 计分方式 |
| --- | ---: | --- |
| C2 构造问答系统、C3 构建 Agent 系统、C4 交付上线 | 各 75 题 | 各含单选 50 题、多选 25 题；单选 1 分、多选 2 分 |
| 综合卷 | 75 题 | 单选 50 题、多选 25 题；满分 100 分 |
| C5 总结与展望 | 10 题 | 显示正确率 |
| C2—C5 按课时练习 | 22 节，每节最多 30 题 | 显示正确率 |

多选题只有所选选项与标准答案**完全一致**才计为正确，不给部分分。75 题试卷会按 80 分练习参考线显示“通过”或“未通过”；C5 短卷和课时练习不设置合格线。

每套试卷的答题进度、最近成绩、累计用时和错题集保存在当前浏览器的本地存储中。刷新后可继续答题；更换浏览器、清除网站数据或更换本地文件路径时，进度可能无法自动继承。数据不会同步到 GitHub。

## 题库维护

- 章节卷、综合卷和课时题目分别保存在 `llm_acp/*.md` 与 `llm_acp/课时题库/*.md`。
- 修改 Markdown 后，在仓库根目录运行 `python3 llm_acp/build_quiz.py`，重新生成 HTML 内嵌题库。
- 运行 `node llm_acp/test_quiz.js`，核对题目、答案与主要答题流程。生成脚本需要 Python 3.9 或更高版本；测试脚本需要 Node.js。

生成后的 `刷题.html` 是独立文件。只修改 Markdown 而不重新生成时，网页仍会显示旧题目。
