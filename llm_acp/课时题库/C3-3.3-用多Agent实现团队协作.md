# 3.3 用多Agent实现团队协作｜课时练习

依据：`aliyun_acp_learning/大模型ACP认证教程/C3_构建Agent系统/3_3_用多Agent实现团队协作.ipynb` 的公开内容。共 12 题：单选 8 题、多选 4 题。题目为课程练习题，并非官方真题。

## 一、单选题（1—8）

**1.** 一项任务需要同时完成资料检索、财务分析和报告撰写，且各步骤职责清楚。哪种多 Agent 协作模式更合适？
A. 只做关键词匹配　B. 主管规划、专家执行的分层模式　C. 不分工的单 Agent　D. 随机选一个工具
> 来源：章节卷 C3-20

**2.** 开放式创意问题需要多个角色交换观点，更适合哪种模式？
A. 只读文件模式　B. 纯向量检索　C. 共创协作模式　D. 固定的单步流程
> 来源：章节卷 C3-21

**3.** 多 Agent 分工的核心价值是什么？
A. 保证每个角色都使用同一提示词　B. 免去所有验证　C. 保证零成本　D. 让不同角色处理擅长的部分并整合结果
> 来源：章节卷 C3-22

**4.** 多 Agent 系统通常需要权衡什么？
A. 质量收益与额外调用成本、延迟　B. 只看 Agent 名字　C. 只看提示词字数　D. 是否使用彩色界面
> 来源：章节卷 C3-23

**5.** 如果两个 Agent 的输出互相矛盾，下一步最合理的是？
A. 删除用户需求　B. 设置协调或审查机制核对依据　C. 随机挑一个　D. 直接合并矛盾结论
> 来源：章节卷 C3-24

**6.** 多个专家 Agent 分工后，谁应负责汇总并检查最终结果？
A. 只依靠最后发言者　B. 协调或上层角色　C. 浏览器缓存　D. 随机一个工具
> 来源：课时 3.3 新题

**7.** 开放式创意任务中，角色之间来回交换草案，更接近哪种模式？
A. 共创协作　B. 固定窗口截断　C. 模型蒸馏　D. 单次函数调用
> 来源：课时 3.3 新题

**8.** 多 Agent 方案质量提升很小却显著增加调用和延迟，合理结论是？
A. 仍必须保留所有角色　B. 评估是否简化分工　C. 继续无限增加 Agent　D. 只换角色名字
> 来源：课时 3.3 新题

## 二、多选题（9—12）

**9.** 分层规划模式通常包括哪些职责？
A. 汇总并检查各部分结果　B. 所有角色完全不沟通　C. 上层拆解与分配任务　D. 专家角色执行子任务
> 来源：章节卷 C3-61

**10.** 共创协作模式比较适合哪些特点？
A. 多视角互相激发　B. 需要讨论和整合观点　C. 只能处理固定机械步骤　D. 问题开放、答案不唯一
> 来源：章节卷 C3-62

**11.** 多 Agent 方案的评估应考虑哪些因素？
A. 最终可用质量　B. 调用次数和延迟不会影响多 Agent 方案的评价　C. 协调成本　D. 只看 Agent 数量越多越好
> 来源：章节卷 C3-63

**12.** 分层规划模式中常见的职责有哪些？
A. 上层拆解任务　B. 专家执行子任务　C. 上层无需查看或检查各部分结果　D. 每个角色完全独立且不交流
> 来源：课时 3.3 新题
